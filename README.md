# 📚 Curso de Git e GitHub

Repositório criado para registrar meus estudos, práticas e desafios realizados durante o curso de **Git e GitHub**.

O curso aborda desde os conceitos fundamentais de controle de versão até recursos utilizados no desenvolvimento colaborativo, como **branches, merges, Pull Requests e Forks**.

---

## 🎯 Objetivos do curso

Durante o curso, foram trabalhados conceitos fundamentais e intermediários de Git e GitHub, incluindo:

* Controle de versões;
* Repositórios locais e remotos;
* Commits;
* Histórico de alterações;
* Stage;
* Branches;
* Merges;
* Resolução de conflitos;
* Pull Requests;
* Forks;
* Trabalho colaborativo;
* Sincronização entre repositórios locais e remotos.

---

# 📖 Conteúdo do curso

## 1️⃣ Introdução ao Git e GitHub

Neste capítulo foram apresentados os conceitos fundamentais do Git e do GitHub e o fluxo básico de trabalho com controle de versões.

### Conteúdos estudados

* Salvando a primeira versão de um projeto;
* Salvando uma nova versão através de commits;
* Clonando um projeto;
* Modificando um projeto;
* Utilização do `git log` para consultar o histórico de versões;
* Entendendo o `git status`;
* Entendendo a área de Stage;
* Utilização do `git diff`;
* Recursos de **Source Control do VS Code**;
* Utilização do `git checkout`;
* Arquivo `.gitignore`.

### Desafio

Desafio prático realizado ao final do capítulo para aplicar os conceitos estudados.

# 2️⃣ Resolvendo Problemas Comuns

Neste capítulo foram estudadas situações comuns encontradas durante o uso do Git, incluindo formas de desfazer alterações, trabalhar com históricos diferentes e solucionar problemas de sincronização.

### Conteúdos estudados

* Desfazendo modificações não salvas;
* Removendo arquivos da área de Stage;
* Entendendo o editor Vim;
* Deletando o último commit sem deletar as modificações nos arquivos;
* Deletando o último commit juntamente com as modificações nos arquivos;
* Atualizando o repositório local em relação ao repositório remoto;
* Resolvendo um `push` rejeitado por históricos diferentes;
* Resolvendo `pull` com conflito;
* Sobrescrevendo um histórico no GitHub;
* Apontando um projeto para outro repositório remoto.

### Desafio
